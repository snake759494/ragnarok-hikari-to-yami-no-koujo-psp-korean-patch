# 기술 문서

## 디스크 구성
| 경로 | 내용 | 처리 |
| --- | --- | --- |
| `PSP_GAME/SYSDIR/EBOOT.BIN` | 암호화된 실행 파일(~PSP) | 복호화한 평문 ELF로 교체, 문자열 치환 |
| `PSP_GAME/USRDIR/GAMEDATA.CFI` | 메인 아카이브(약 4,500개 파일) | 재구성 |
| `PSP_GAME/INSDIR/GAMEDATA.CFI` | 설치용 사본(PGD 암호화) | 사용하지 않도록 경로 변경 |
| `USRDIR/system/fonts/JPN7pt.PGF`, `JPN12.PGF` | 게임 전용 폰트(서브셋) | 한글 글리프 추가 |
| `USRDIR/system/ccc/jis2ucs.bin`, `ucs2jis.bin` | libccc 문자 변환표 | 한글 매핑 추가 |
| `USRDIR/movie/op1.pmf` | 오프닝 동영상 | 자막 합성 후 재인코딩 |
| `PSP_GAME/PARAM.SFO` | XMB 정보 | 제목 변경 |

## GAMEDATA.CFI
- 헤더: `u8 디렉터리 수`, 디렉터리마다 `u8 길이 + 이름("…/") + 개수`, 파일마다 `u8 길이 + 이름 + u32 오프셋 + u32 크기`. 개수가 0xFC 이상이면 `0xFC + u16`.
- 데이터는 헤더 끝(0x1560F)부터, 오프셋은 0x800 정렬. 대부분 `u32 원본 크기 + gzip`.
- `tools/cfi.py` 가 파싱·재구성(무변경 재구성이 원본과 바이트 단위로 일치).

## 스크립트(.rtz)
- 컴파일된 스크립트. 앞에 심볼 해시 테이블, 뒤에 바이트코드, 파일 끝에 **문자열 상수 해시 테이블**(`varint 개수, (u32 해시, varint 길이, 바이트)…`, 해시 오름차순, 일부는 해시 0xFFFFFFFF 길이 0 센티넬로 끝).
- 바이트코드는 문자열을 해시로 참조하므로, 해시를 유지한 채 문자열만 바꾸면 길이 제한이 없습니다(`tools/strtab.py`).
- 번역 배치의 문장 순서는 바이트코드 안의 해시 참조 순서로 복원했습니다(`tools/make_batches.py`).
- `＊＊＊＊リト＊＊＊＊` 는 주인공 이름으로 치환되는 토큰이라 그대로 둡니다.

## 문자 인코딩과 폰트
- 게임은 Shift-JIS → JIS → (jis2ucs.bin) → 유니코드 → PGF 글리프 순으로 그립니다.
- 번역에 쓰인 한글 음절 1,164자에 JIS 제1수준 한자 코드(0x3021~)를 차례로 배정하고, jis2ucs/ucs2jis 표를 그 한글 코드포인트로 바꿨습니다(`tools/kcode.py`). 가나·영숫자·기호는 원래 코드 그대로입니다.
- PGF에는 실제 한글 코드포인트로 글리프를 추가합니다. 글리프가 2,048개를 넘으면서 charmap/charptr 비트폭이 늘어나며, 기존 「없음」 표식값(2^bpe−1)과 새 인덱스가 겹치지 않게 표식을 먼저 옮깁니다(`tools/build_font.py`).
- 본문 폰트 JPN7pt에는 반각 영문 소문자가 없어 번역문에서 쓰지 않았습니다.

## 실행 파일 문자열
- 평문 ELF의 0x37A000~0x398000 구간 Shift-JIS 문자열 풀(4바이트 정렬). 각 문자열은 원래 슬롯(다음 4바이트 경계까지) 안에서 제자리 치환합니다(`tools/eboot_extract.py`, `tools/eboot_text.py`).
- 세이브·설치·메시지 대화상자용 UTF-8 문자열 27개는 별도 표로 치환.
- 설치 데이터 경로 `ms0:PSP/SAVEDATA/NPJH50431DAT/GAMEDATA.CFI` 를 존재하지 않는 이름으로 바꿔 항상 디스크 데이터를 읽게 했습니다.
- 이름 입력 금지어 목록은 가나 이름을 거르는 기능이라 원문을 유지합니다.

## 그림 글자(GIM)
- `.giz`(GIM) 와 `.gmz`(GMO 모델에 내장된 GIM). 모두 8비트/4비트 팔레트(RGBA8888) 형식.
- `tools/tex_patch.py` 가 사양(JSON: 지우기·복사·글자 그리기·회전·발광 보정)대로 이미지를 고친 뒤 같은 크기 팔레트로 재양자화해 제자리에 넣습니다.
- 이벤트 제목·지역명·승패 조건 라벨은 `tools/gen_label_specs.py` 로 자동 생성합니다.

## 동영상
- `op1.pmf` 의 H.264 스트림을 디코드해 일본어 자막 위쪽에 한글 자막(흰 글자, 검은 테두리)을 합성하고, x264로 다시 인코딩해 원래 PMF 컨테이너 슬롯에 맞춰 넣습니다(파일 크기 동일, `tools/movie_op1.py`, `tools/op_mux.py`).
- 자막 구간은 화면 하단 흰 글자 픽셀로 검출했습니다(`tools/movie_detect.py`).
